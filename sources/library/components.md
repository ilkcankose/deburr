# Components

Ready-made UI pieces you can copy, install or hand to a coding agent.

## Bencho
https://bencho.dev/ · React + Motion · freemium (Pro €79/yr)

- **What:** About 143 live, tweakable micro-interaction blocks tagged by gesture: crumpled receipt, page peel, dynamic island, slosh slider, magnifying dock. It also has an infinite canvas for tuning, a sound library and credited "finds" from X.
- **Best for:** Tactile, playful interaction ideas.
- **Its design:**
  - Motion: springs everywhere; base ease `(.22,1,.36,1)` plus many overshoots.
  - Color: warm light neutrals (`#f7f7f6`, `#17181a`).
  - Shape: 999px pills and glass effects.
- **Maker:** Lorenzo Cabra.

## libraries.dev
https://libraries.dev/ · React, React Native, SwiftUI · free (MIT), Studio Pro $9/mo

- **What:** Effect packages for AI products: border beam, thinking orbs with 9 states, gooey, voice glow, bot avatars, liquid metal, image loader and magnetic UI.
- **Best for:** Signature details for AI interfaces that don't look stock.
- **Its design:**
  - Motion: one ease everywhere, `(.22,1,.36,1)`. Dropdowns open in 250ms and close in 150ms, starting from scale .97.
  - Color: one blue, `#0071fc`.
  - Elevation: a "material" shadow with a 1px ring.
- **Maker:** Jakub Antalik.

## Rare UI
https://www.rareui.com/components · React, shadcn · free

- **What:** 27+ unusual animated components: fluid orb, gooey nav, proximity sidebar, duration picker, voice note.
- **Best for:** One distinctive component in a shadcn/Tailwind project.
- **Its design:**
  - Type: Cal Sans with Open Runde.
  - Color: orange `#FC4C01`, also used for focus.
  - Shape: an "Apple" bevel on dark pills made of three inset hairlines.
- **Maker:** Swami Malode.

## ReactDrops
https://reactdrops.dev/ · React, WebGL · free (custom license)

- **What:** 9 expressive components (liquid glass orb with AI states, topographic terrain, refracted text, fan gallery), each with deep prop control and an "AI-ready brief".
- **Best for:** One "wow" hero or AI-orb moment.
- **Maker:** Cris Javier.

## loading.dev
https://loading.dev/ · React 19 · free

- **What:** 29 crafted spinners with a playground for size, color and speed. Reduced motion is respected.
- **Best for:** A spinner that isn't the default one.
- **Its design:**
  - Color: warm off-black (`#141413`) and one orange (`#ef551a`).
  - Type: Inter with `cv01`/`ss03` and a 450 weight.
- **Makers:** Jakub Krehel and Paul Faivret.

## 21st.dev
https://21st.dev/community/components · React, Tailwind · freemium (2 free copies a day)

- **What:** About 12K community components, 306 templates and 941 themes. Each copies as an agent prompt or installs via CLI or MCP.
- **Best for:** Quickly finding a hero, pricing or AI-chat section, or surveying how a pattern is usually built.
- **Its design:**
  - Type: General Sans.
  - Color: OKLCH tokens.
  - Motion: iOS sheet curve `(.32,.72,0,1)`.

## Sprrrint
https://sprrrint.com/ · Figma, Framer · freemium (Pro $19/30 days)

- **What:** About 380 copy-paste marketing sections (hero, pricing, footer, bento), plus gradients and templates.
- **Best for:** Blocking out a marketing site in Figma or Framer fast.
