# Tools

Software to design, build or ship with.

## Efecto
https://efecto.app/ · browser canvas + MCP · freemium (from $4.99/mo)

- **What:** A design canvas (artboards, layers, auto-layout) that AI agents drive through about 68 MCP tools. It has Figma import, React/Tailwind export and an FX mode with 30+ ASCII, dither and halftone effects.
- **Best for:** Letting Claude Code lay out pages or social graphics on a canvas you can edit.
- **Maker:** Pablo Stanley.

## Endless Tools
https://endlesstools.io/ · browser · freemium (Pro $20/mo)

- **What:** No-code 3D, type, materials, lighting and effects workspace for key visuals. Exports up to 8K, video, USDZ, GLB and web embeds.
- **Best for:** Exploring 3D logos and key visuals without Blender.

## Remotion
https://www.remotion.dev/ · React, Node, Lambda · free for teams of up to 3

- **What:** Make videos and motion graphics with React code. About 35 templates, including captions, audiograms and prompt-to-video. It also has an embeddable player.
- **Best for:** Data-driven or templated product videos.

## Spektral
https://motion-gpu.dev/ · Svelte, React, Vue · free

- **What:** A lean WebGPU runtime for fullscreen WGSL shaders and multi-pass effects. There's no WebGL fallback.
- **Best for:** Custom shader backgrounds without three.js.
- **Maker:** Marek Jóźwiak.

## fig.page
https://dub.co/tools/figma-link-shortener · free

- **What:** Branded short links for Figma files and prototypes, by Dub.
- **Best for:** Clean Figma links in a CV, case study or deck.
