# Animation

Motion references, recordings and ready-made transitions.

## 60fps
https://60fps.design/ · iOS (some web) · freemium (Pro $15/mo)

- **What:** 2,125 recorded interactions from 494 apps, each described frame by frame. You can filter by gesture, pattern, effect and element. It also has SwiftUI code snippets, storyboards and an MCP.
- **Best for:** Finding the exact reference for a specific micro-interaction, sometimes with SwiftUI code.
- **Its design:**
  - Color: strict grayscale with no brand color.
  - Media: video tiles that play on hover, 20px card radius.
  - Motion: 150ms ease-out, with an overshoot `(.175,.885,.32,1.275)` on transforms.

## Spotted in Prod
https://www.spottedinprod.com/ · iOS · freemium ($8.99/mo, $199.99 lifetime)

- **What:** 1,000+ short iOS interaction clips in phone frames, each credited to its app and maker. Tags cover gesture, pattern, flow, visual and design language. It also runs a jobs board.
- **Best for:** High-craft iOS gestures and micro-interactions.
- **Its design:**
  - Type: Helvetica Neue with Departure Mono.
  - Color: one orange, `#ff6a00` (also defined in Display-P3).
  - Shape: `corner-shape: superellipse(1.25)` for native-feeling corners.
  - Motion: named eases (snappy, swift, smooth) and 48 reduced-motion blocks.

## Transitions.dev
https://transitions.dev/ · web · freemium (Pro $12/mo, $149 lifetime)

- **What:** 43+ production UI transitions in CSS and React: modal, dropdown, toast, tabs, number pop, success check, streaming text, thinking states. They're built on shared motion tokens. It also has a Motion Skill for coding agents and a CLI that scores a codebase's motion.
- **Best for:** A sensible default set of product transitions.
- **Its design:**
  - Motion tokens are published:
    - Durations: 80/150/250/350/400/500ms, with a 40ms stagger.
    - Main ease: `(.22,1,.36,1)`.
    - Bounce: `(.34,1.36,.64,1)`.
    - Blur: 2/3/8px. Press scale: 0.96–0.99.
  - Type: Saans with Inter.
- **Maker:** Jakub Antalik.

## Make It Animated
https://makeitanimated.dev/ · React Native · paid one-time (tiered, about $69 now)

- **What:** About 104 React Native recreations of famous app animations (TikTok feed, Telegram profile header, Find My, page curl), built with Reanimated, Gesture Handler and Skia.
- **Best for:** Native-feeling mobile motion with real code.
- **Its design:**
  - Dark UI with a coral `#ff4a3d`.
  - Type: Outfit, with the comic display face Bangers.
- **Maker:** Vadim Serbulenko.

## Origami Archive (dpark)
https://origamiarchive.com/ · prototypes · free

- **What:** 54 Origami Studio interaction prototypes (2021–2024), each a looping video with a downloadable source file. Examples: "CD Peel", "Gooey playbar", "Seesaw toggle".
- **Best for:** Taking apart high-craft micro-interactions from apps like Typo and Universe.
- **Its design:** Deliberately plain, using Inter on zinc. The videos are the design.
