# AI design skills and review

Projects that give coding agents design judgment, or review what they make. These are the closest neighbors to this pack, so they're useful for positioning.

| Project | What it does |
| --- | --- |
| [Taste Skill](https://www.tasteskill.dev/) | Open-source skill files that stop agents from generating generic frontends |
| [Impeccable](https://impeccable.style/) | One skill, 20 commands and curated anti-patterns, for Cursor, Claude Code, Gemini CLI and Codex |
| [UI Skills](https://www.ui-skills.com/) | Skills to polish agent-built interfaces |
| [jakubkrehel/skills](https://github.com/jakubkrehel/skills) | Agent skills for animation, typography, layout and color |
| [rams](https://www.rams.ai/) | Automated design review for AI-generated code: accessibility and visual bugs |
| [Agentation](https://www.agentation.com/) | Visual feedback tool for agents |
| [BrandKernel](https://brandkernel.io/) | Personal brand guide written for AI tools |
| [Popmelt](https://popmelt.com/) | Design alongside AI inside your codebase |
| [Refero Styles](https://styles.refero.design/) | AI-readable DESIGN.md files for 2,000+ sites (see [Inspiration](inspiration.md)) |
| [Transitions.dev](https://transitions.dev/) | Motion skill and motion-scoring CLI (see [Animation](animation.md)) |
| [Spotkit](https://getspotkit.vercel.app/) | Illustration skill (see [Generators](generators.md)) |
| [Efecto](https://efecto.app/) | Canvas that agents drive through MCP (see [Tools](tools.md)) |
| [Design Tokens Generator](https://design.dev/ai/design-tokens-generator/) | Brand colors or Figma export into semantic tokens |
