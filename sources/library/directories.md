# Directories

Lists of other resources. Good starting points for finding more.

## Designeer
https://www.designeer.xyz/ · free

- **What:** About 750 hand-reviewed items: resources, tools, inspiration, portfolios and curated "finds" from X. You can filter by discipline, color and price.
- **Its design:**
  - Type: Funnel Display.
  - Color: cyan `#0bf` accent.
  - Motion: named eases (out, spring, drawer, morph) and view transitions between routes.
- **Maker:** Dhruv Jaradi.

## DesEngs
https://desengs.com/ · free

- **What:** A dated list of about 111 design-engineering resources, filterable by verb (Read, Watch, Use, Build…). Plus 111 inspiration sites and 196 "super minimal" sites.
- **Its design:**
  - Type: Instrument Serif, Geist and IBM Plex Mono.
  - Color: dark zinc.
  - Decoration: blueprint style, with slowly rotating dashed circles, 45° hatching and corner tick marks.

## mkdir
https://mkdir.directory/ · free

- **What:** 34 free inspiration galleries ranked by visitor votes.
- **Its design:** A model of restrained list micro-interactions:
  - Rank numbers blur-swap on hover.
  - A hover plate travels between rows.
  - Vote counts roll like an odometer.
  - Eases are named (lift, swap, morph, plate).
- **Maker:** Edoardo Lunardi.

## Built by Designers
https://builtbydesigners.com/ · free

- **What:** 169 apps, tools and sites built by designers.
- **Its design:**
  - Type: TWK Lausanne at very light weights (250–350).
  - Easter egg: a hidden Mac OS X Aqua desktop mode.
- **Makers:** Juliette and Phil Hedayatnia.
