# Generators

Tools that make visuals from parameters: gradients, shaders, textures, 3D, illustrations.

## Shader Gradient
https://shadergradient.co/ · Figma, Framer, React, Vue · freemium (from about $2/mo)

- **What:** Moving 3D mesh gradients (plane, sphere, water), tuned by speed, density, camera, colors and grain. Export as React code, URL, Figma plugin or Framer component.
- **Best for:** A live animated hero gradient.
- **Maker:** ruucm.

## Feral UI Gradients
https://feralui.dev/gradients · Figma, image, video · free

- **What:** 20+ gradient types (mesh, grainy, aurora, wave, pixel, wallpaper). Presets come from traditional Japanese colors (e.g. 桜吹雪 "Sakura wind"). Export as SVG, PNG or MP4, or as editable Figma layers.
- **Best for:** Characterful soft gradients and wallpapers.
- **Maker:** Sarthak Navalekar.

## Liquid Orb Editor
https://lersent001.github.io/orb/ · Web (WebGPU), SwiftUI · free (MIT)

- **What:** An editor for animated liquid-glass AI orbs. 13 presets (Siri Wave, Liquid Chrome, Neural Plasma), glass shell controls, idle/thinking states and audio response. Exports Web or SwiftUI code.
- **Best for:** A voice or assistant orb that has to match on web and iOS.

## Grainrad
https://grainrad.com/ · browser (WebGPU) · free

- **What:** Turns images, video or 3D into about 20 effects: ASCII, dithering, halftone, VHS, CRT. It has retro palettes (GameBoy, C64, Risograph) and many dither algorithms. Export as PNG, GIF, MP4, SVG or Three.js.
- **Best for:** Lo-fi, retro and terminal textures.
- **Its design:** A terminal UI: `#0a0a0a`, mono type, square corners, phosphor green.

## Oddgrid
https://oddgrid.vercel.app/ · files · free

- **What:** Seeded generative pixel-grid art with riso-style palettes and loopable motion (flow, scan, pulse, shimmer). Export as PNG, SVG, animated SVG or video.
- **Best for:** Pixel textures and loopable brand motifs.

## Sketch Tools
https://sketchdesign.club/ · browser (WebGL) · freemium ($14.98/mo)

- **What:** Stackable audio, MIDI and mic-reactive visual tools (particles, ferrofluid, Chladni, CRT, liquid metal). Export as video, Lottie or GLB.
- **Best for:** Music visuals, teasers, live projection.
- **Its design:**
  - Color: acid lime `#C9FF41` on near-black.
  - Motion: drawers on the iOS curve.

## Morflax Studio
https://studio.morflax.com/ · browser · freemium (Pro about $9/mo)

- **What:** 3D mockups (devices, apparel, branding), abstract shapes, 3D icons and SVG-to-3D. 200+ elements, export up to 4K.
- **Best for:** Fast, polished device mockups and product reveals.

## Brik
https://brik.space/Gallery · browser · freemium ($12/mo)

- **What:** Built by Wix. You describe a visual and it builds a reusable, parameterized tool (hero backgrounds, posters, type systems) that you can use or remix.
- **Best for:** Repeatable on-brand generative assets.
- **Its design:**
  - Type: HAL Matex with Neue Haas Grotesk.
  - Motion: a signature hover curve `(.87,0,.13,1)`.

## Spotkit
https://getspotkit.vercel.app/ · Claude Code / Codex skill · free

- **What:** Turns a one-sentence feature description into a minimal SVG spot illustration. A strict style system keeps a set consistent: 12 layouts, one stroke weight, 12 theme variables.
- **Best for:** 20 matching empty-state or onboarding illustrations.
- **Its design:**
  - Color: warm greige (`#EDEAE6`) with a green accent (`#3E9077`).
  - Type: Libre Baskerville with Geist.
- **Maker:** Devesh Shirsath.
