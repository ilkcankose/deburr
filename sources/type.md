# Type

Patterns observed across the sites in the [library](library/README.md).

- **One meaning per weight.** Wellmade: 400 reads, 500 is pressable, 600 is the one big thing.
- **Font features on.** loading.dev sets Inter with `cv01`/`ss03` and a 450 weight. Mobbin enables `dlig` and `ss07`.
- **`text-wrap: balance`** on headings (Wellmade).
- **Mono or pixel faces for meta.** Geist Mono, Geist Pixel and Departure Mono show up for numbers, dates and labels.
